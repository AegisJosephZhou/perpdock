## X：已核实的原文及适用范围

官方自动化页标注 **Updated April 2026**，核对位置为页面开头、I. Ground Rules / Don’t、II.B.2 及 II.B.3。原文短引合计 24 个英文词：

- 自动化定义中的关键限定：**“repeated actions without a person actively performing them”**。
- 禁止项中的关键片段：**“Use non-API-based forms of automation”**，同一项以网站脚本为例。
- AI 自动回复机器人所需许可：**“requires prior written and explicit approval from X”**。

原文：[X 自动化规则](https://help.x.com/en/rules-and-policies/x-automation)。因此以前关于非 API 自动化及 AI 回复机器人需许可的说法有官方依据，但必须保留限定，不能扩张成“所有 AI 起草的帖子都禁止”。批量关键词自动回复、无人值守回复 bot 属该规则重点；自动回复还要求接收方明确表达接收意愿、可退出和每次互动最多一条等条件。

**本次区别：**用户发起一次任务、少量逐条阅读上下文、每条单独审阅，不等于搭建长期无人值守 bot；AI 辅助起草后由真人主动决定并发布，也不能只因用了 AI 就认定为 AI reply bot。**但由代理经 UI 执行发布仍不是 API，且“用户同意这次任务”不等同平台明文豁免。官方页没有专门说明 Codex/CUA 这类有监督代理，也没有确认“一次或少量 UI 自动点击”例外。**不能向用户保证这种执行方式已获 X 许可，亦不宜单凭该页对一切有监督单次辅助作确定禁令。以上是适用性分析，平台最终分类仍不确定。

记录须准确：如果每条实际只由代理阅读和审稿，不能写成“人类逐条审阅”或“真人手动发布”；用户对整个任务的授权与真人逐条操作是不同事实。

内容层面，X 禁止批量或重复垃圾内容、无关推广回复、操纵热词与互动量；正常相关讨论并非因为涉及产品就一概被禁。[X 真实性政策](https://help.x.com/en/rules-and-policies/authenticity)

## 筛选与发送条件

| 项目 | 本轮操作界限 |
|---|---|
| 原创帖 | 每平台先一条；X 中文/英文为二选一候选，避免同一账户连续发布近似广告；OK 星球以站内需求讨论为主，无外链或外部报名入口 |
| 适合回复 | 对方真实讨论稳定币、钱包、Gas、桥接步骤或 HL 入金困难；先读完整原帖及已有回复，回答具体问题后再简述开发背景 |
| 不适合回复 | 单纯行情/价格帖、与入金无关的热门帖、项目官方群公告下重复贴产品、已有拒绝或明显厌恶推广的讨论；不能仅凭关键词命中就发 |
| 最小回复 | 一条聚焦该上下文的问题或有用解释；不复制同一广告，不贴转账地址、不求转发点赞、不承诺收益；若无人回应，不追着连续提醒 |
| 执行检查 | 确认目标平台、当前账号与最终文案；看到验证码、风控提示或内容限制即停止该平台动作，不换号/换词规避；失败后先检查是否已发送，不盲目重试造成重复 |
| 反馈记录 | 保存公开帖子 URL、发布时间、文案版本、相关上下文、真实回复和意愿；记录“未回复”而不伪造需求，按问题类别归纳而不采集敏感财务数据 |

本轮不应扩大为持续监控、定时自动回帖、无人值守关键词 bot、私信营销或付费推广。X 的工具执行适用性保留上述不确定性，不能伪装为真人手动行为，也不能以“少量”作为规避自动化规则的理由。
