# Brand and network artwork

The funding page uses Perpex's existing gold mark, Hyperliquid's dark symbol, and artwork identifying each supported source network. Network names remain visible beside the selected network icon. Assets are bundled locally; displaying them does not contact a third-party image server or change wallet or payment behavior.

Artwork, colors, proportions and supplied clear space are preserved. The OP Mainnet SVG receives the equivalent `viewBox="0 0 1024 1024"` so its original fixed-size artwork scales correctly at icon size; its paths and colors are unchanged. Base uses its current Square, not the earlier circular symbol.

SVG files contain static local shapes and colors only, with no scripts, event handlers, external references or embedded images. PNG originals are retained. Marks identify the corresponding services and networks; they do not imply endorsement. Brand ownership and applicable usage guidelines remain with each owner.
