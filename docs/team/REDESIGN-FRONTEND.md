# 原型方向的前端产品化

实施范围严格为 App.tsx/styles.css；保留 wallets/api/payment 原始资金路径。两个主屏通过真实状态自动判断：未付款 awaiting_signature/expired 留入金页；本机 submission/sourceTx 或后台后续资金状态进入进度；历史为独立可访问面板，导航禁止在 busy 时切单，恢复未读出前不显示新付款表单。

保持可访问标签：付款网络与资产、支付金额、你的 HL 接收地址、连接钱包、连接 EVM 钱包填入、收款地址确认复选框、25%、50%、全部、获取实时入金报价、确认报价，创建订单、授权本笔额度、钱包签名并付款、订单记录、继续核验已提交交易。全部动态金额仅真实 api/wallet 结果。

快捷金额算法：以真实钱包余额为基数乘25/50/100%，整数单位向下取整，每个结果再取服务端单笔上限较小值。例如余额20,000/上限10,000：25%=5,000；50%=10,000；全部=10,000。未知余额禁用，单笔上下限/Tron另需TRX同时显示。

视觉：米白/炭黑/深绿，520px 单列；桌面不加手机外壳，移动横向无固定宽度。目标净额突出，接收地址完整可编辑；报价/账户权益次级折叠；主动作根据报价/订单/授权状态逐步呈现。
